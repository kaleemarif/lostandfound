# Lost & Found Hub

I built this as a simple Lost & Found website for my college.

Right now, users can report lost and found items through forms, and I’ve added some demo posts to show how it will look.

## 🚀 What it does
- Report lost items  
- Report found items  
- Clean and responsive UI  
- Demo posts with images  

## 🛠 Tech Used
- HTML  
- CSS  
- JavaScript  

## 📌 What I’m working on next
- Connecting it to a database (Firebase)  
- Showing real posts on the website  
- Image upload support  
- Matching system (lost ↔ found items)
